# Assets Folder

This folder contains local copies of external assets to ensure games work on school computers without internet access.

## Folders:
- `fonts/` - Google Fonts (download and place CSS/font files here)
- `cdn/` - Cloudflare CDN assets (download and place files here)
- `jsdelivr/` - jsDelivr CDN assets (download and place files here)
- `jquery/` - jQuery library files (download and place files here)

## How to populate:
1. Download the external assets that games reference
2. Place them in the corresponding folders
3. Ensure the file structure matches what the games expect

## Note:
Some games may still reference external URLs. You may need to manually update those games to use local assets.
