How to install a mod (Minecraft 1.21.11)

1. Install a mod loader: Fabric or NeoForge (choose 1.21.x).
2. Download the mod's .jar file (make sure it supports 1.21.11).
3. Copy the .jar into the mods folder above.
4. Open the Minecraft Launcher and start the loader profile (Fabric/NeoForge).
5. Launch the game — your mods are now loaded!

Tip: press Win + R, paste the copied path, hit Enter and the folder opens in File Explorer. The "Open mods folder" button saves the same batch file next to this site.
